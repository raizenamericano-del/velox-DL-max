Punya aplikasi sendiri? Pakai API-nya

VELOX menyertakan JSON API. Tanpa key untuk pemakaian wajar — rate limit berlaku per IP.

curl -X POST /api/resolve \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://www.tiktok.com/@tiktok/video/7460937381265411370"}'

Balikan: title, thumbnail, author, dan items[].formats[] berisi tiap opsi kualitas beserta URL download.

# proxy CDN langsung (cepat, tanpa encode)
GET /api/dl?t=direct&u=<cdn-url>&n=<nama-file>

# lewat engine (merge video+audio / konversi MP3)
GET /api/dl?t=engine&u=<page-url>&f=<format>&a=mp3

Semua URL di dalam respons /api/resolve sudah menunjuk ke endpoint ini — tinggal pakai.

curl /api/health
# {"status":"ok","engine":{"version":"…","ffmpeg":true},"cache":{…}}

Dipakai Railway sebagai health check, dan menampilkan versi engine + statistik cache.

Pertanyaan yang sering muncul

Apakah benar-benar gratis? Ada batasnya?

Gratis, tanpa akun. Yang dibatasi hanya jumlah request per menit per IP supaya server tidak kewalahan — tunggu sebentar lalu lanjut lagi.

Kenapa video TikTok saya tidak ada watermarknya?

VELOX mengambil berkas sumber dari CDN TikTok, bukan hasil render aplikasi. Karena itu watermark tidak pernah ikut terbawa.

Video Instagram saya gagal diambil. Kenapa?

Biasanya karena post bersifat privat, dihapus, atau butuh login. VELOX memakai dua metode (engine + halaman embed publik). Kalau keduanya gagal, konten memang tidak bisa diakses tanpa sesi akun.

Apakah file saya disimpan di server?

Tidak. Media dialirkan langsung ke perangkatmu. Server hanya memakai berkas sementara saat harus menggabung video+audio, lalu dihapus begitu selesai.

Bisakah download playlist YouTube?

Bisa. Tempel link playlist, VELOX menampilkan daftar videonya (maks. 30 item) dan tiap item bisa diunduh sendiri.

Legal tidak sih?

VELOX hanya mengambil konten publik yang memang bisa kamu lihat di browser. Hak cipta tetap milik pembuatnya — gunakan untuk arsip pribadi, dan minta izin sebelum memakai ulang karya orang lain.
